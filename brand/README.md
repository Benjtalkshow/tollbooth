# Tollbooth brand

The mark is a barrier gate with its arm lifted: payment parked at the booth, work passes, the barrier lifts. The arm is striped in the accent green so the mark still reads at 16px.

## Files

| File | Use |
|---|---|
| `logo-mark.svg` / `.png` | app icon, avatars, social profile, 512 px tile on dark |
| `logo-mark-light.svg` / `.png` | same tile for light backgrounds |
| `favicon.svg` / `.png` | browser tab, tiny sizes; no stripes, thicker strokes |
| `logo-horizontal-dark.svg` / `.png` | wordmark lockup on dark |
| `logo-horizontal-light.svg` / `.png` | wordmark lockup on light |
| `banner.svg` / `.png` | 1280 × 640 GitHub social preview, README header, npm, X |

Everything is vector. Re-render PNGs with headless Chrome or any SVG rasteriser; do not scale the PNGs up.

## Type

Inter for everything, 650 weight for the wordmark with tight tracking. JetBrains Mono for addresses, amounts, hashes and code.

## Rules

- Keep the arm at 24 degrees. It is lifted, never horizontal and never vertical.
- Minimum clear space around the mark equals the width of the post.
- Do not recolor the arm, add gradients to it, or put the mark on a busy photo.
- Tagline, always with the full stop: **Escrow for software that pays software.**
